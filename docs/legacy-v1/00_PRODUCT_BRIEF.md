# Product Brief — Call On

## Product definition

Call On is a private, request-first coordination network for trusted communities. It converts an informal “Does anybody have…?” message into a structured Ask, collects private contributions, records accepted commitments, coordinates logistics, and closes the loop.

## Initial user and environment

- Adults in one existing HOA/neighborhood community.
- The community already communicates in a WhatsApp group.
- Members range from highly technical to people who rarely install or learn new applications.
- The pilot is member-led and private.

## User promise

> Get something done with help from people nearby, without inventory homework, public awkwardness, or losing track of who has what.

## Core behavior

```text
Need arises → create Ask → share to WhatsApp → neighbor offers → requester accepts
→ coordinate privately → handoff/help → return/complete → thank → optional memory
```

## Why it should remain active

The system activates around demand rather than depending on people browsing a static catalog. Supply is learned progressively after a real contribution. The request link is the acquisition unit; the successful completion is the retention unit.

## North-star metric

**Completed neighbor assists per activated Circle per 30 days.**

A neighbor assist counts only when:

- an Ask has at least one accepted contribution;
- the contribution reaches completed/returned state;
- no unresolved incident blocks completion.

## P0 proof

The pilot must demonstrate that structured Ask links produce faster, clearer, and more reliably completed help than an ordinary WhatsApp thread, without introducing unacceptable privacy, safety, or social-pressure costs.
