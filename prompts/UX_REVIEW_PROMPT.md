# UX Review Prompt

Review the rendered implementation against `docs/04_UX_INFORMATION_ARCHITECTURE.md`, `docs/05_DESIGN_SYSTEM.md`, `visuals/VISUAL_GUIDANCE.md`, and the prototype screenshots.

Test at 390px mobile and desktop. Evaluate:

- Can a WhatsApp visitor understand and contribute without onboarding friction?
- Does Ask creation start from one natural-language field?
- Is identity requested only after contribution intent?
- Is each screen’s primary action obvious?
- Are exact address and private identities hidden at the correct times?
- Are empty/loading/error/expired/permission states designed?
- Is the home action-oriented rather than feed-like?
- Is progressive inventory optional and delayed?
- Are tap targets, focus, contrast, zoom, labels, and motion accessible?
- Does the UI feel neighborly rather than transactional or HOA-admin-heavy?

Return prioritized findings with screenshots, affected screen IDs, and concrete changes. Do not propose features outside P0.
