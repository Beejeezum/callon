# Visual Guidance

## Files

### `01-flow-first-mobile-ux-board.png`

Useful for:

- Complete happy-path sequencing.
- Warm, friendly mobile tone.
- Progressive item saving.
- WhatsApp share moment.

Do not copy:

- Every displayed screen into P0 navigation.
- Decorative density or marketing-poster layout.
- Any text that conflicts with the PRD.

### `02-product-overview-and-dashboard-board.png`

Useful for:

- Admin/dashboard organization.
- Explaining the end-to-end product.
- Simple green/white system.

Do not copy for member P0:

- Desktop SaaS inventory emphasis.
- “Join first” onboarding as the first shared-link experience.
- Large feature-list marketing panels.

### `03-lean-mobile-flow-spec-board.png`

Useful for:

- Primary mobile flow.
- Simple hierarchy and restraint.
- Shared Ask → Offer → Plan → Return progression.

Do not copy:

- Public ratings shown in any generated example.
- Any generic “feed” implication.
- Exact mock dates or sample identities.

### `prototype-contact-sheet.png` and `prototype-screenshots/`

These are the preferred tone and behavior references for the first implementation. They show:

- Warm cream/green/coral palette.
- Natural-language Ask start.
- Action-oriented home.
- Scoped shared Ask.
- Contribution choices.
- Active Loan timeline.
- Completion/status sharing.
- Separate pilot admin console.

## Build interpretation

Use a restrained composite:

- Behavioral flow from the prototype and visual 03.
- Warm visual language from the prototype and visual 01.
- Admin density only from visual 02.
- One primary CTA per screen.
- Fewer cards than the large boards show.
- Real responsive web layouts, not phone-device mockups.

Before completing a UI task, capture 390px mobile and at least one desktop screenshot and compare against this guidance.
